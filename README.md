# HEXIRON GAMES

ربات تلگرامی ۱۰ بازی (۲ رایگان + ۸ Premium) با سیستم سطح/رتبه (XP/Coins)،
رتبه‌بندی، دعوت دوستان، اتاق‌های چندنفره واقعی **یا تک‌نفره در برابر هوش
مصنوعی**، منوی کاملاً بدون دستور (بدون `/`)، و اتصال به **HEXIRON SALES**
برای فروش اشتراک.

## تغییرات این نسخه (آماده‌سازی برای فروش در فروشگاه + حالت هوش مصنوعی)

### ۱) تک‌نفره در برابر هوش مصنوعی، برای هر بازی گروهی
هر اتاق گروهی (حکم، مافیا، گرگینه، منچ) حالا یک دکمه‌ی «🤖 تک‌نفره با هوش
مصنوعی» دارد که بلافاصله جای خالی را با بازیکن‌های ربات پر می‌کند و بازی را
شروع می‌کند — نیازی به منتظر ماندن برای بقیه‌ی اعضای گروه نیست:

- **حکم:** حاکمِ هوش مصنوعی خودش حکم را (بر اساس خالِ غالب در ۵ کارت اول)
  انتخاب می‌کند؛ هر نوبتِ هوش مصنوعی خودش کارت قانونی و نسبتاً هوشمند بازی
  می‌کند (اول تلاش برای بردن ارزان‌ترین دست ممکن، وگرنه کمترین ضرر).
- **مافیا / گرگینه:** نقش‌های هوش مصنوعی شب خودشان هدف را انتخاب می‌کنند
  (مافیا/گرگینه هدف تصادفی از بین بی‌گناهان، دکتر/پیشگو هدف تصادفی) و روز
  خودشان رأی می‌دهند — کاملاً مطابق همان مکانیزم «پایان زودهنگام فاز» که
  برای بازیکن‌های واقعی وجود داشت.
- **منچ:** نوبت‌های هوش مصنوعی خودکار تاس می‌ریزند و نتیجه به‌صورت خلاصه در
  یک پیام نشان داده می‌شود (نه یک پیام جداگانه به‌ازای هر تاس).

هر سه موتور (حکم، مافیا، گرگینه) با یک شبیه‌سازی کامل «۴ تا ۶ بازیکن، همه
هوش مصنوعی» از ابتدا تا پایان بازی تست شدند تا مطمئن شویم زنجیره‌ی تصمیم‌های
پشت‌سرهم هوش مصنوعی بدون خطا کامل می‌شود.

### ۲) سیستم پیشرفت (سطح و رتبه)
یک لایه‌ی سطح/رتبه روی همان XP موجود اضافه شد (بدون نیاز به migration
دیتابیس) — هرچه سطح بالاتر برود، XP بیشتری برای سطح بعد لازم است. رتبه‌ها:
نوآموز → برنزی → نقره‌ای → طلایی → الماس → اسطوره. در «پروفایل» و «رتبه‌بندی»
نمایش داده می‌شود.

### ۳) استفاده کاملاً بدون دستور (بدون `/`)
یک کیبورد ثابت پایین صفحه (🎮 بازی‌ها / 👤 پروفایل / 🏆 رتبه‌بندی / 🎁 جایزه
روزانه / 👥 دعوت دوستان / ❓ راهنما) با اجرای `/start` برای کل چت فعال می‌شود —
از آن به بعد، همه‌ی اعضای گروه می‌توانند فقط با زدن دکمه از پایین صفحه با
ربات کار کنند، بدون این‌که هیچ‌وقت نیاز باشد چیزی با `/` تایپ کنند. زدن
«🎮 بازی‌ها» همان پنل بازی را مستقیماً داخل چت گروه (برای دید همه‌ی اعضا) باز
می‌کند. دستورات قبلی (`/games`, `/profile`, ...) هم برای سازگاری با نسخه‌های
قبلی همچنان کار می‌کنند.

## این نسخه چه چیزی را نسبت به نسخه اولیه تغییر داده؟

### ۱) اتصال به فروش اصلاح شد (باگ بحرانی)
نسخه اولیه به یک endpoint ساختگی (`/license/check`, بر اساس `user_id`+`game`) وصل
می‌شد که در ریپازیتوری واقعی `hexiron-sales` اصلاً وجود ندارد. اگر بدون این
اصلاح دیپلوی می‌شد، Premium برای هیچ‌کس هرگز فعال نمی‌شد.

اتصال درست (که الان پیاده شده) دقیقاً با `hexiron-sales/api.py` مطابقت دارد:

```
GET {SALES_API_URL}/api/v1/license?product=hexiron-games&group_id=<chat_id>
Header: X-API-Key: <SALES_API_KEY>
```

**نکته مهم معماری:** لایسنس در HEXIRON SALES بر اساس `(product_id, group_id)`
ذخیره می‌شود — نه بر اساس کاربر، و نه بر اساس بازی. یعنی:

- یک خرید محصول «hexiron-games» برای یک **چت مشخص** (گروه یا پیام خصوصی)،
  همه‌ی ۸ بازی Premium را برای همان چت باز می‌کند — دقیقاً مثل ربات‌های گارد و
  موزیک شما.
- **پیش‌نیاز:** باید از پنل ادمین همان ربات Sales، محصولی با شناسه دقیقاً
  `hexiron-games` (یا هر مقداری که در `SALES_PRODUCT_ID` گذاشتید) بسازید، وگرنه
  همیشه `active:false` برمی‌گردد.

اگر Sales API موقتاً در دسترس نباشد یا نخواهید هنوز وصلش کنید، از پنل
`/admin` → «مدیریت لایسنس» می‌توانید لایسنس هر چت را دستی و موقت فعال کنید.

### ۲) باگ‌های رفع‌شده
- **دوز (TTT):** حالا فقط سازنده اتاق می‌تواند روی صفحه ضربه بزند؛ قبلاً هر
  کسی در گروه می‌توانست بازی شخص دیگر را دستکاری کند.
- خطاهای تلگرام دیگر بی‌صدا قورت داده نمی‌شوند؛ لاگ می‌شوند.
- شرط مسابقه (race condition) در جایزه روزانه رفع شد.
- `.dockerignore` اضافه شد؛ نسخه‌های کتابخانه‌ها pin شدند.
- کاربران مسدودشده (`/admin` → مسدودسازی) دیگر جایی در ربات بازی نمی‌کنند.

### ۳) موتور کامل بازی‌های گروهی
نسخه اولیه فقط نقش/کارت پخش می‌کرد و همان‌جا متوقف می‌شد. الان:

- **مافیا:** فاز شب (مافیا/دکتر/کارآگاه با دکمه خصوصی) + فاز روز (رأی‌گیری
  علنی) + شرط برد/باخت واقعی + پایان‌دادن زودهنگام فاز وقتی همه رأی دادند، وگرنه
  بعد از مهلت زمانی (قابل تنظیم با env).
- **گرگینه:** همان ساختار، بدون دکتر، با نقش پیشگو.
- **حکم:** حکم واقعی — ۵ کارت اول به حاکم، انتخاب خال حکم، پخش ۱۳ کارته کامل،
  رعایت اجباری خال، حکم‌زنی، شمارش دست تا ۷ تریک، امتیاز مسابقه تا ۷ دست، چرخش
  حاکم بعد از هر دست.

همه‌ی این سه موتور با شبیه‌سازی کامل بازی از ابتدا تا پایان (از طریق همان
callback dispatcher واقعی که تلگرام استفاده می‌کند) تست شده‌اند، نه فقط
syntax-check.

### ۴) پنل ادمین قوی‌تر
`/admin` حالا منو دارد: آمار کلی (کاربران، بازی‌های انجام‌شده، لایسنس‌های فعال)،
لیدربرد، پیام همگانی (broadcast با throttling)، فعال/غیرفعال‌سازی دستی لایسنس هر
چت، و مسدود/رفع‌مسدودی کاربر.

## راه‌اندازی

```bash
cp .env.example .env
# BOT_TOKEN, OWNER_ID, SALES_API_URL, SALES_API_KEY, SALES_BOT_USERNAME را پر کنید
pip install -r requirements.txt
python main.py
```

متغیرهای مهم در `.env.example` مستند شده‌اند.

## دیپلوی روی گیت‌هاب + لیارا

```bash
git init
git add -A
git commit -m "hexiron-games: fix sales license integration, complete mafia/werewolf/hokm engines"
git branch -M main
git remote add origin https://github.com/<user>/<repo>.git
git push -u origin main
```

روی Liara:
1. یک اپ جدید از نوع **Docker** بسازید و به این ریپازیتوری وصل کنید (یا با
   `liara deploy` از CLI).
2. دیسک persistent با نام `data` (در `liara.json` تعریف شده) را روی `/data`
   مانت کنید — دیتابیس SQLite همان‌جا نگه داشته می‌شود.
3. متغیرهای محیطی `.env.example` را در تنظیمات اپ روی Liara وارد کنید (به‌خصوص
   `BOT_TOKEN`, `SALES_API_URL`, `SALES_API_KEY`, `SALES_PRODUCT_ID`,
   `SALES_BOT_USERNAME`).
4. پورت `8080` (health check) از قبل در `liara.json` تنظیم شده.
5. در پنل ادمین ربات **hexiron-sales**، محصول `hexiron-games` را با پلن(های)
   دلخواه بسازید — بدون این مرحله هیچ خریدی لایسنس واقعی فعال نمی‌کند.

## ساختار پروژه

```
main.py            راه‌انداز اصلی، health server، ثبت هندلرها
config.py          تنظیمات از env
db.py              SQLite: کاربران، رویدادها، لایسنس هر چت
sales.py           اتصال به HEXIRON SALES (اصلاح‌شده)
admin.py           پنل مدیریت
games/
  engine.py        Room، دوز، دک کارت مشترک
  catalog.py       متن/دیتای بازی‌های ساده
  handlers.py      روتینگ همه‌ی دکمه‌ها و دستورها
  mafia.py         منطق خالص مافیا (قابل تست بدون تلگرام)
  werewolf.py      منطق خالص گرگینه
  hokm.py          منطق خالص حکم
  social.py        اتصال مافیا/گرگینه به تلگرام + زمان‌بندی فازها
  hokm_flow.py     اتصال حکم به تلگرام
```

## توسعه‌های آتی پیشنهادی (خارج از این نسخه)
- مهاجرت از SQLite به Postgres وقتی تعداد گروه‌های فعال زیاد شد (کد با الگوی
  repository نوشته شده تا این مهاجرت راحت باشد).
- افزودن Redis برای وضعیت اتاق‌ها اگر روزی بیش از یک instance ربات هم‌زمان
  اجرا شود (فعلاً وضعیت اتاق‌ها در حافظه‌ی پردازش نگه‌داری می‌شود).
- افزودن پلن رایگان آزمایشی (trial) از سمت Sales.
